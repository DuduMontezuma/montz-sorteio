## Sobre o projeto

O **Montz Sorteio** é uma aplicação web simples, rápida e responsiva para realizar sorteios de números aleatórios. O usuário define um intervalo (valor mínimo e máximo) e o sistema gera um resultado na hora. Este projeto foi desenvolvido para colocar em prática conceitos de lógica matemática com JavaScript e responsividade em CSS.

## Funcionalidades

- **Intervalo Personalizado:** O usuário pode escolher os números de início e fim para o sorteio.
- **Geração Aleatória:** Utilização dos métodos matemáticos nativos do JavaScript (`Math.random`, `Math.ceil` e `Math.floor`) para garantir um sorteio justo e preciso.
- **Design Responsivo:** A interface se adapta perfeitamente a dispositivos móveis e telas menores.

## Tecnologias Utilizadas

- **HTML5:** Estrutura e semântica.
- **CSS3:** Estilização, layout Flexbox e Media Queries para responsividade.
- **JavaScript:** Manipulação do DOM e lógica matemática para a geração do número aleatório.
